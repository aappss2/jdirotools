📖 Quick Guide: Understanding Z-Scores

What is a Z-Score? A Z-score (standard score) shows how many standard deviations a value is from the mean. It's a standardized way to compare numbers from different distributions.

Formula

Z = (X - μ) / σ

Interpretation

Z = 0 → value at mean. Z > 0 → above mean. Z < 0 → below mean. |Z| ≥ 3 often indicates an outlier.

Applications

  • Education — comparing test scores across exams.
  • Finance — scoring models and anomaly detection.
  • Medicine — growth charts and clinical measurements.
  • Machine Learning — feature standardization.

Example

Mean = 70, SD = 10, X = 85 → Z = (85 - 70) / 10 = 1.5 → ~93rd percentile

❓ Frequently Asked Questions

What is a Z-Score?

A Z-Score tells you how many standard deviations a value is from the mean.

How do I calculate probability from Z?

Use the standard normal CDF — our probability tab handles common cases quickly.

What if σ = 0?

σ must be > 0. If σ = 0, the distribution has no spread and Z is undefined.

Quick Reference

Common z-values and percentiles:

  • Z = 1 → ~84.13%
  • Z = 1.645 → 95% (one-tailed)
  • Z = 1.96 → 97.5% (two-tailed, 95% CI)
  • Z = 2 → ~97.72%
