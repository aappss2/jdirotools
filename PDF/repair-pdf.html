Auto Repair tries to fix the existing PDF structure by correcting errors, rebuilding cross-references, and patching damaged sections. It preserves the original file structure as much as possible. Full Rebuild creates an entirely new PDF by extracting all recoverable pages from the damaged file and assembling them into a fresh document. Use Full Rebuild if Auto Repair doesn't fully fix the issue.
