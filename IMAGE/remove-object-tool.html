About This Object Removal Tool

This tool uses OpenCV.js in-browser inpainting to remove unwanted objects from photos. You simply paint a white mask over the object you want removed and run the Inpaint operation. The algorithm fills the masked area by sampling nearby pixels, producing a natural-looking fill without uploading your image to any server.

How to use

  1. Upload your photo.
  2. Use Paint to mark the object (white mask). Use Erase to refine.
  3. Choose algorithm (TELEA or Navier–Stokes) and radius (3–5 works for many cases).
  4. Click Inpaint and preview the result. Download when satisfied.
